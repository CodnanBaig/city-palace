# City Palace Museum Jaipur — Luxury Next.js Redesign Concept

A modern, editorial redesign concept based on the current public content and visual assets of citypalace.org.

## What is included

- Next.js 15 App Router project
- Responsive homepage with full-screen hero, horizontal collections rail and luxury editorial sections
- Visit page with ticket cards, Royal Tour, opening hours, Jaipur Centre for Art and official visitor map
- Collections page using the existing museum image library
- About, Food & Drink, Shop, Contact, Research and Careers pages
- Local copies of the public photography used in the concept
- Official public City Palace visitor brochure PDF
- CSS-only motion and IntersectionObserver reveals (no animation library required)
- Mobile navigation and reduced-motion support

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000

## Design direction

The redesign intentionally keeps the current site's restrained sans-serif typography direction rather than introducing a decorative royal font. The visual system is upgraded with large editorial typography, archival photography, deep mineral tones, Jaipur terracotta, museum-like spacing, subtle arch geometry and stronger image-led storytelling.

## Asset note

The included photography and brochure were sourced from the current City Palace Museum public website/CDN for the purpose of this redesign concept. Production usage should follow the museum's own rights and licensing requirements.
